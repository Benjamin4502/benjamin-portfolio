Featured Build

Glowsbyniffy — Shopify conversion landing page

A Nigerian skincare brand needed a dedicated landing page for its traditional stretch-marks-and-scar oil — one product, five variants, built to convert. I designed and coded the entire section from scratch inside the Shopify theme editor, on a phone, end to end.

Shopify Liquid JavaScript Sense Theme (OS 2.0) HTML / CSS Built entirely on mobile
sections/glows-landing.liquid
01{% for variant in product.variants %} 02  <option value="{{ variant.id }}" 03    data-compare="{{ variant.compare_at_price }}"> 04    {{ variant.title }} // 5 variants, one form 05  </option> 06{% endfor %}

Dynamic price comparison

Selecting a variant updates a live strikethrough "compare at" price alongside the sale price and a SALE badge — built so customers see the saving before they commit, not after.

Variant-aware product image

A small product photo switches automatically to match the selected variant, sourced directly from Shopify's CDN via Liquid's image_url filter.

Conversion-tuned CTA

Replaced a generic "Add to Cart" with direct, problem-naming copy: "I need to get rid of my stretch marks / scars" — tested directly against the brand's actual customer language.

Theme conflict resolution

Diagnosed and removed a duplicate variant-picker section left over from the Sense theme defaults that was rendering a second, conflicting Add to Cart form.
